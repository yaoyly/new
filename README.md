# 爪爪接力站

奶油色、极简手账风手机网页，原生 HTML / CSS / JavaScript，无构建依赖。所有猫狗、图标和商品示意均以 SVG 路径原创绘制，无外部图片、字体或网络资源。

## 打开

直接双击 `index.html`。也可在本目录运行 `python -m http.server 8080`，访问 `http://localhost:8080`；手机与电脑同一网络时，访问电脑局域网 IP 的 8080 端口（需系统允许网络访问）。

## 可体验内容

- 首页：搜索、分类、成色与价格筛选。
- 商品详情：尺寸、适用宠物、演示质检档案、拟定处理标准。
- 购物车：添加、修改数量、移除、确认模拟订单；我的页面查看购买记录。
- 出闲置：真实本地图片预览、信息校验、回收或捐赠选择、预约意向、申请进度。
- 消息：申请通知、独立爱心足迹、明确标识的示例机构反馈；回忆册空状态。
- 我的：本地申请数量、回收进度、循环护照。

## 演示边界

数据仅保存于当前浏览器 localStorage，不包含后端、真实估价、支付、物流、机构合作或消毒证明。进度不会自动伪造为已完成。反馈插画不是实际宠物使用照片。切换浏览器或清除站点存储后无法取回本地记录。上传照片仅在当前内存预览，不上传、不长期存储。请使用虚构地址及号码。
